# Limitations and Threats to Validity (ArchSynth v2.2 Recalculation)

1. **Ground-truth availability**: Only `nav2` (`eval/ground_truth/nav2/ground_truth.json`) and `jaco2_sim_devkit` (`eval/ground_truth/jaco2_sim_devkit/ground_truth.json`) have manually curated ground-truth datasets. `slam_toolbox`, `ros2_control`, and `behaviortree_cpp` lack verified ground-truth datasets, so their Precision, Recall, F1, ARI, and NMI are reported as `N/A` rather than fabricated.
2. **Scope differences between Nav2 and JACO2**: Nav2 ground truth (`core_scope` = 13 canonical servers; `extended_scope` = 22 production nodes) represents a curated subset of Nav2's 30 extracted production nodes and 285 interface declarations, which lowers Nav2 precision (`0.4483` core nodes, `0.1493` topics) relative to JACO2 (`1.0000` across a full-repository 11-node inventory). These scores are not directly equivalent without accounting for ground-truth scope.
3. **LLM Mode B unavailability**: `google-generativeai` and `ollama` Python packages are not installed in the active Python 3.11 environment, so LLM-only, Static + LLM, and Mode B (`skip_llm=False`) experiments could not execute and are marked `unavailable`.
4. **Runtime ROS 2 observation unavailability**: The host environment is Windows without an active ROS 2 DDS middleware graph; `runtime_observation_available` is `False` across all six runs.
5. **Basename matching convention**: Per `eval/evaluator.py` (`compute_fuzzy_prf1`), topic/service/action basenames strip namespaces (`arm_controller/joint_trajectory` and `gripper_controller/joint_trajectory` both map to `joint_trajectory`, yielding 8 unique basenames from 9 qualified JACO2 source topics).
6. **Express.js commit variance**: Checked-out `case_studies/express` is at commit `a3714473feb3d2908add734d340e7755fd85e0a3` (recorded verbatim in `evaluation_manifest.json`).
